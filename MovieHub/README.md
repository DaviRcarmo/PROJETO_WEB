# 🎬 MovieHub

O MovieHub é uma aplicação mobile para gerenciamento e organização de filmes.

O projeto foi desenvolvido com finalidade educacional, utilizando React Native, Expo e TypeScript.

## 🎯 Objetivo

Demonstrar, de forma prática, o desenvolvimento de uma aplicação mobile utilizando React Native, Expo e TypeScript, aplicando uma estrutura organizada e modular.

O projeto também tem como objetivo trabalhar conceitos de criação de interfaces, navegação entre telas, reutilização de componentes e organização do código.

## 🎥 Funcionalidades

* Login
* Cadastro de usuário
* Tela inicial
* Listagem de filmes
* Cadastro de filmes
* Detalhes do filme
* Edição de filmes
* Exclusão de filmes
* Filmes favoritos
* Pesquisa
* Filtros
* Gêneros
* Ordenação
* Estatísticas
* Compartilhamento de filmes
* Cinemas próximos
* Galeria e câmera
* Trailer do filme
* Perfil do usuário
* Configurações

## 📚 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/DaviRcarmo/PROJETO_WEB.git
```

### 2. Acesse a pasta do projeto

```bash
cd PROJETO_WEB/MovieHub
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o aplicativo

```bash
npx expo start
```

Após iniciar o Expo, execute o aplicativo utilizando o Expo Go ou um emulador online compatível.
